# the quota monitor's normalized snapshot and refresh safety

The common `RateWindow` contains used percentage, optional duration in minutes, reset time, and a derived remaining percentage. The Codex mappers convert both HTTP `WindowSnapshot` and CLI RPC windows to it: HTTP `reset_at` is Unix seconds, `limit_window_seconds / 60` gives duration; CLI RPC has its own duration/reset fields. `CodexReconciledState` reconciles HTTP usage, plan, and identity before publication. The OAuth strategy's result builder accepts a partial credit-only response with `primary: nil`, and marks malformed rate-limit data `unknown` rather than publishing an invented zero.

This snapshot answers “how much of this account's current allowance is used, and when does that allowance reset?” It does not reveal all per-request token counts. Credits, monthly spend limits, and model-specific limits are distinct fields; do not collapse them into the primary percentage. A five-hour window and a weekly window can both gate the next request, so store both with their own reset times.

The app's `ProviderRefreshCoordinator` coalesces concurrent refreshes per provider instance and assigns a generation to a replacement request. `UsageStore+Refresh` checks that generation before applying results. Codex's account-state guard additionally compares account identity/auth fingerprint so a slow fetch for account A cannot overwrite the display after switching to account B. The adaptive timer advances from scheduled ticks and skips missed ticks, avoiding overlapping catch-up refreshes.

For a combined app, make each live probe return `{provider, account_scope, source, fetched_at, windows[], credits?, confidence, credential_owner}`. Publish only if the refresh generation and credential/account scope still match. Cache the last valid snapshot with its timestamp, but distinguish stale cached data, unavailable quota, a confirmed empty window, and a real zero-percent reading. Respect 429 `Retry-After`; a transient failure should not rewrite known usage as zero. Keep optional credit enrichment tied to the same credential snapshot that produced the quota result.
