# Archived planning documents

These are the original planning documents written before and during the first
implementation pass. They are kept for provenance and are **not current**.

- `PROJECT.md` — the initial end-to-end project specification.
- `REQUIREMENTS.md` — the original functional and non-functional requirements.
- `STACK.md` — the original technology selection and rationale.
- `PLAN.md` — the original phased execution plan.

For the current state of the project, read `docs/DEVELOPMENT_STATE.md`,
`docs/ROADMAP.md`, and `TODO.md` instead.
