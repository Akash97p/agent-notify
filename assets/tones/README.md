# Built-in notification tones

These four tones (chime.wav, ping.wav, alert.wav, knock.wav) are original works generated synthetically for AgentNotify.

They are released under CC0 1.0 Universal (public domain) — no attribution required.

The files are embedded into the application and seeded into the user's sound directory on first run.

Users may add their own WAV or MP3 files through Settings > Sounds without affecting the built-ins.

They remain available offline and are safe to redistribute with the app.
