Local human-attention broker

AgentNotify

Your coding agents can ask for input, report blockers and announce finished work without it being lost in a terminal you are not looking at. Everything runs on this machine.

Installed and ready
1

Send one yourself

Open PowerShell, Command Prompt, or a new WSL shell and run:

agentnotify.exe send ^
  --type input_required ^
  --priority high ^
  --title "Need your decision" ^
  --message "Choose option A or B."
In Bash or WSL, replace each ^ with \ — or put it all on one line.
2

Teach your coding agent

The skill is a Markdown file that tells an agent when to notify you. The fastest way to install it is the tray icon: right-click it and choose Install agent skill…, which opens the Install tab with a button for each agent it knows.

From a terminal, the same thing:

agentnotify.exe install-skill claude
agentnotify.exe install-skill codex --scope project
Claude Code
~/.claude/skills/agentnotify/
Codex
~/.agents/skills/agentnotify/
OpenCode
~/.config/opencode/skill/agentnotify/

Using something else? Copy the file and drop it wherever that agent loads skills from.

3

Use the right signal

The type decides how long a notification lives. The four on the left need you and stay until you resolve them; the four on the right report and fade.

input_requireda decision blocks progress
permission_requiredapproval needed
blockedwaiting on something external
erroran operation failed
completedthe work is finished
successa step worth knowing about
warningworth a look, not urgent
infoa milestone; use sparingly

Give a recurring condition a stable --key so an update replaces the old notification instead of stacking another one beside it, and clear it when it is answered: 

agentnotify.exe health
agentnotify.exe list --unresolved true
agentnotify.exe resolve NOTIFICATION_ID
4

Optional: reach your phone

By default nothing leaves this computer. If you want notifications to follow you, open Settings → Channels and connect an AgentNotify Relay — a small server you host yourself. Your phone pairs with it by scanning a QR code, and from then on the same agentnotify send reaches both the desktop and the phone.

The relay never sees what your notifications say. Each one is encrypted for a specific device before it leaves this machine, and the push that wakes the phone carries no content at all — so write messages that make sense to someone away from their desk.
