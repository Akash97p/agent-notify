Get started

Install once. Notify from anywhere.

01

Install

Download AgentNotifySetup.exe from GitHub Releases. The self-contained per-user installer adds the CLI to PATH and starts the tray broker.

02

Check

agentnotify.exe health

Run this once near the beginning of an agent task.

03

Notify

agentnotify.exe send \
  --type input_required \
  --title "Need a decision" \
  --message "Choose A or B."

Agent integration

One small skill, every capable agent.

Download or copy the bundled SKILL.md from the tray. Agents with skill discovery can install it in their skills directory; other tools can use the same policy in project instructions or a system prompt.

Stable keys update unresolved conditions in place. Agents capture the returned ID and resolve it when attention is no longer needed.

Architecture

Local truth, optional delivery.

Coding agents→Authenticated loopback API→SQLite lifecycle→WPF toast + center

The tray process owns the API, history, notification center, and custom non-activating toast stack. Opt-in webhook, SMTP, and Telegram adapters subscribe after local persistence through a durable outbox, so network failures can never lose or reject a local notification.
